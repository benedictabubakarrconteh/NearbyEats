# NearbyEats

A modern Android app to discover nearby restaurants using Google Places API.

## Setup

1. Get API Key: https://console.cloud.google.com/
2. Replace `YOUR_GOOGLE_API_KEY` in MainActivity.kt
3. Build: `./gradlew build`
4. Run: `./gradlew installDebug`

## Features

- Search nearby restaurants
- View ratings and locations
- Open in Google Maps
